# Claim quality

- Separate Measured / Observed / Inferred / Unverified claims (using the document's language).
- Keep descriptions brief and concrete. No mandatory metaphors or adjectives.
- Exact CSS values and property names are allowed. Preserve raw values if adding a converted HEX value.
- Functional roles follow observed use. Do not label a frequent color "brand primary" without supporting controls/assets.
- Describe fontFamily as a CSS stack unless the rendered font is independently verified.
- Do not promise a complete design system, pixel-perfect reproduction, or an exact breakpoint based on two viewport samples.
- Guidance and optional prompts do not introduce undocumented states, tokens, assets, or behavior.
- State partial coverage plainly. Prefer "not observed" to a fabricated default.
