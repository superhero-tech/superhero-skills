# Optional descriptive language

Use plain descriptions alongside exact values, when helpful:

- "rounded corners, 8px on all four corners";
- "three product columns at 1440px; one at 390px";
- "soft shadow: 0px 2px 8px rgba(0, 0, 0, 0.1)";
- "blue primary button background: rgb(37, 99, 235)".

Color names, metaphors, and typeface personality descriptions are optional. They must not replace measurements, imply an unverified functional role, or create rules absent from the source. CSS property names and accurate technical notation are welcome when they make implementation clearer.
