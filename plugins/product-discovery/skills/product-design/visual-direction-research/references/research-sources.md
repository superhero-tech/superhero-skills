# Discovery across the open web

Use this reference when starting or expanding research. Do not restrict discovery to a maintained gallery list.

## Start with the brief, not a gallery

Translate the user's language into several search axes:

- Product and task: directory, search results, comparison, editorial reading, checkout, dashboard.
- Visual language: typographic, expressive, warm, restrained, experimental, industrial, playful, image-led.
- Content constraints: text-heavy, many filters, long names, low asset budget, multilingual.
- Adjacent industries with similar interaction patterns.

For example, a bold job-board brief may lead to searches for creative recruitment, cultural event catalogs, independent marketplaces, editorial directories, and typographic search interfaces. Search actual products as well as inspiration collections. Vary the query only when it tests a different hypothesis, rather than repeating cosmetic keyword changes.

Track the candidate's source and relevance. Select contrasting mechanisms, not several near-identical palettes. Keep enough functional similarity to judge how the direction behaves under the user's information load.

## Example repositories — optional seeds

Use clean root URLs. Verify availability, live site names, and capabilities during the research; this table does not guarantee their current features.

| Source | Starting hypothesis | Check before selecting |
| --- | --- | --- |
| [Awwwards](https://www.awwwards.com/) | Expressive art direction, unusual composition, interaction concepts | Does the direction support usable inner pages and the target task? |
| [Commerce Cream](https://commercecream.com/) | Product brands and creative commerce | Is personality in the UI or mostly expensive photography and packaging? |
| [Recent](https://recent.design/) | Contemporary web, interfaces, branding and motion | Is this a live website, a concept, a template, or a single visual fragment? |
| [Hoverstates](https://www.hoverstat.es/) | Alternative and experimental web design | Can the interaction be inspected, and can its mechanism transfer? |
| [A1 Gallery](https://www.a1.gallery/) | Discovery by website type and visual characteristics | Follow the original site; distinguish templates and sponsored material. |

These are examples, not a required checklist or whitelist. Supplement them with general web search, live sites the user already knows, relevant product directories, brand websites, and agency/designer case studies.

Do not treat tracking links, copied citation fragments, image-proxy URLs, or reposted inspiration threads as original design evidence. Resolve the actual site when possible.

A gallery advertising an MCP server does not mean that integration is available or required. Prefer connected capabilities when sufficient; do not install or authorize new access just to perform ordinary visual research.

## Selection rationale

For each finalist, explain:

1. The part of the brief it answers.
2. The visual mechanism worth studying.
3. Its functional fit and content/asset dependencies.
4. What it contributes relative to the other finalists.
5. Whether the source is live, historical, conceptual, or only partly accessible.

Keep rejected candidates in working notes only when the rejection explains a consequential research choice. Do not inflate the deliverable with every search result.
